# 로컬 탭 보관함 (Local Tab Vault) 2.0.0

Firefox 계열 브라우저(Firefox, LibreWolf, Floorp 등)용 탭 보관함 확장입니다. 열린 탭을 저장해 두고 하나씩 확인하며 정리할 수 있습니다. 선택하면 [hitomi-web](https://github.com/parang149) 서버와 연동해 여러 PC에서 같은 보관함을 실시간으로 함께 쓸 수 있습니다.

## 주요 기능

- **열린 탭 보관**
  - 현재 창이나 모든 일반 창의 탭을 보관함에 저장합니다.
  - 저장한 뒤 보관함을 다시 읽어 제대로 들어갔는지 확인하고, 확인창을 거쳐 탭을 닫습니다. 확인창은 설정에서 끌 수 있습니다.
  - 같은 주소는 기존 항목과 합칩니다.
  - 저장하지 않는 탭: about: 같은 브라우저 내부 탭, 로딩 중인 탭, supjav 목록 페이지
  - 저장한 뒤 주소 등이 바뀐 탭은 닫지 않습니다. 창의 탭이 모두 닫히게 되면 빈 새 탭 하나를 남깁니다.
- **정리**(관리 화면)
  - 이미 보관함에 있는 열린 탭만 골라 닫습니다. 새로 저장하지는 않습니다.
- **작업 시작**
  - 켜 두면 보관함 항목을 열어 보고 그 탭을 닫았을 때 그 항목을 완료로 처리하고, 다음 미완료 항목을 엽니다.
- **목록**
  - 미완료, 완료, 휴지통 탭과 출처 필터(전체/supjav), 검색, 정렬(최신순 등)을 씁니다.
  - 관리 화면에서는 목록 보기와 그리드 보기를 바꿀 수 있습니다.
  - 항목 ⋮ 메뉴에서 상세 보기(썸네일, 수집 날짜, 포스트 날짜 등), 메모와 태그 편집, 완료, 휴지통 이동을 합니다.
- **supjav 수집**
  - 사용자가 연 supjav 일본어 목록 탭을 쪽마다 넘기며 글 주소, 제목, 썸네일, 날짜를 보관함에 넣습니다.
  - 화면에 보이는 순서(좌상단 → 우하단)를 그대로 유지합니다.
  - Cloudflare 확인 화면이 뜨면 사용자가 그 탭에서 직접 통과할 때까지 기다립니다. 자동으로 통과하는 기능은 없습니다.
  - 수집과 열린 탭 보관은 동시에 실행되지 않습니다.
- **백업**(관리 화면)
  - 전체 JSON, TXT, HTML로 내보내거나 JSON에서 가져옵니다. 내보내는 파일에는 서버 연동 주소(토큰)가 들어가지 않습니다.

## 서버 모드 / 로컬 모드

- **로컬 모드**(기본, 연동 꺼짐): 보관함은 이 PC 브라우저 안(IndexedDB)에만 있습니다. 외부로 아무것도 보내지 않습니다.
- **서버 모드**(관리 화면 › 연동 › 연동 켜기)
  - hitomi-web 서버의 보관함이 기준이 되고, PC의 보관함은 그 사본으로 쓰입니다.
  - 바뀐 내용은 곧바로 서버에 올라가고, 다른 PC나 WEBUI에서 바꾼 내용은 1~2초 안에 들어옵니다.
  - 서버에 연결되지 않아도 계속 쓸 수 있습니다. 바뀐 내용은 대기열에 남았다가 연결되면 한꺼번에 올라갑니다.
  - 로컬 모드로 바꾼 뒤 한 작업도 다시 연동을 켜면 서버에 반영됩니다.
  - 서버에 반영된 기록은 연동 탭의 "서버 반영 기록"에서 볼 수 있습니다.
- 서버 모드에는 서버 보관함 API(`/api/vault/{토큰}`)를 지원하는 hitomi-web 서버가 필요합니다.
- LibreWolf는 내부망 http 주소도 https로 바꿔서 연결이 실패합니다. `about:config`에서 `dom.security.https_only_mode.upgrade_local`을 `false`로 바꾸세요.

## 빌드와 설치

```sh
npm install
npm --prefix ui install
npm run build   # ui 화면 빌드 → dist/local-tab-vault-<버전>/
npm test        # 동작 테스트 + 화면 테스트
```

- 브라우저 `about:debugging` → **이 Firefox** → **임시 부가 기능 로드**에서 `dist/local-tab-vault-<버전>/manifest.json`을 고릅니다.
- 확장 ID는 `local-tab-vault@local.invalid`입니다. 같은 ID로 다시 로드하면 데이터가 유지됩니다.

## 구조

- `extension/`: 백그라운드(보관함 DB, 서비스, 서버 동기화, supjav 수집)
- `ui/`: 사이드패널과 관리 화면(Vue 3, Nuxt UI 4, Tailwind 4, Vite 다중 페이지). 빌드하면 `extension/ui/`에 들어갑니다.
- `tests/`: 동작 테스트, `ui/tests/`: 화면 테스트(jsdom)
- `docs/HOW-IT-WORKS.md`: 작동 방식과 변경 내역. `docs/auto-close-plan.md`: 자동 닫기 설계
