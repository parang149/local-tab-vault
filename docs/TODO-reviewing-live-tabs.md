# 예정 작업: 확인 중 상태를 현재 열린 탭 기준으로 표시

상태: 1.7.0 구현 완료. 최종 동작과 검증 결과는 UPDATE-1.7.0.md 참조.

## 요구사항

- ‘확인 중’은 한 번이라도 열었던 항목을 의미하지 않음.
- 현재 브라우저에 해당 URL의 탭이 열려 있는 보관 항목만 ‘확인 중’으로 표시.
- 과거에 열었더라도 현재 열린 탭이 없으면 ‘확인 중’으로 남기지 않음.
- 전체 화면과 사이드패널에 동일 기준 적용.
- 이번 요청에서는 코드를 변경하거나 실제 브라우저 탭을 조작하지 않음.

## 구현 전 정할 세부 기준

- 완료/휴지통 항목과 현재 열림 표시의 우선순위.
- 작업 시작 OFF 상태에서 마지막 탭을 닫았을 때 미확인으로 되돌릴지 여부.
- 기존 작업 ON 상태의 ‘마지막 동일 URL 탭 닫기 → 완료 → 다음 항목 열기’ 흐름과의 연계.
- 동일 URL 탭이 여러 개일 때 마지막 탭이 닫히기 전까지 확인 중 유지.
- 확장 실행·브라우저 재시작 시 현재 열린 탭 조회 및 탭 생성·닫힘·URL 변경 반영.
- 현재 창/모든 일반 창 범위와 비공개 창 제외 기준.

## 검증 계획

- 가상 데이터로 현재 열림, 과거 열림, 동일 URL 여러 탭, URL 이동, 재시작, 작업 ON/OFF 경우를 검증.
- 실제 사용자 탭은 조작하지 않음. 배포는 ZIP 없이 버전별 폴더로 제공.
