# 예정 작업: about: 탭 저장 제외

상태: 1.7.0 구현 완료. 최종 동작과 검증 결과는 UPDATE-1.7.0.md 참조.

## 요구사항

- 사용자가 입력한 `abuot:`는 `about:`를 의미함.
- 탭 보관 시 URL이 `about:`로 시작하는 탭은 저장 대상에서 제외.
- 예: `about:blank`, `about:newtab`, `about:preferences`, `about:debugging`.
- 전체 화면과 사이드패널의 현재 창/모든 일반 창 저장에 동일 적용.
- 수집·저장·검증 개수에서 제외하며, 저장 후 기존 탭 닫기 대상에도 포함하지 않음.
- 기존 보관함에 이미 저장된 about: 항목은 자동 삭제하지 않음.
- JSON 가져오기 및 다른 제한 URL(`file:`, `moz-extension:` 등)의 기존 정책은 이번 작업에서 변경하지 않음.

## 구현 및 검증 계획

1. 공통 탭 수집 단계에서 about: URL을 제외.
2. 저장 안내에 about: 탭 제외를 명시.
3. 일반 URL과 about: URL이 섞인 가상 탭으로 현재 창/모든 창의 저장·검증 개수 확인.
4. about: 탭만 있을 때 저장할 대상 없음으로 처리되고 어떤 탭도 닫히지 않는지 확인.
5. 기존 보관 항목 유지 및 about: 탭이 닫기 대상에 들어가지 않는지 회귀 테스트.
6. 실제 사용자 탭은 조작하지 않고 가상 데이터로 테스트. 배포는 ZIP 없이 버전별 폴더로 제공.
