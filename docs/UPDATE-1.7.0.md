# 1.7.0 변경 및 검증

- 사이드패널 상단의 ‘탭 보관함’을 ‘미완료 N개’로 교체하고 LOCAL 소개 문구 제거. 검색이나 페이지와 관계없는 미완료 전체 개수.
- about: 탭은 현재 창/모든 창 저장에서 제외. 기존 about: 보관 항목과 JSON 가져오기는 그대로 유지.
- 확인 중은 모든 일반 창에서 동일 URL이 현재 열려 있는 미완료 항목에만 표시. 완료/휴지통은 유지. 작업 OFF에서 마지막 탭을 닫으면 미확인으로 표시.
- 현재 열림은 목록 조회 시 계산하므로 과거 열람 기록이나 가져온 확인 중 값만으로 확인 중이 되지 않음. JSON의 저장 상태·열람 기록은 유지되며 가져온 뒤 현재 브라우저 기준으로 표시.
- 열린 항목을 수동 미확인 처리해도 탭이 열려 있으면 확인 중으로 표시됨. 완료 해제는 가능.
- 작업 ON에서 탭 하나를 닫으면 모든 일반 창의 정확히 같은 URL 탭도 닫고, 성공 확인 후 완료 처리 및 다음 미완료 항목 하나 열기. 아래쪽 우선, 없으면 위쪽.
- 중복 닫힘 이벤트와 별도 보관 후 일괄 닫기 이벤트는 작업 완료로 중복 처리하지 않음.
- 비공개/팝업/제한 URL 및 창 전체 닫힘은 작업 대상에서 제외. URL 변경 또는 닫기 실패 시 완료·다음 열기 중단.

## 검증

자동 테스트 35개 통과. 가상 탭 2,000개 저장부터 복원까지 흐름, about: 제외/기존 항목 유지, 현재 열림·URL 이동·재시작·완료 보존, 중복 자동 닫기·실패·반복 이벤트·마지막 항목 위쪽 이동, 사이드패널 헤더 검증 포함.

실제 사용자 탭은 조작하지 않았음. 실제 Floorp 시각 검증은 미실시. 새 버전은 5~10개의 시험 탭으로 먼저 확인할 것.
중복 탭 자동 닫기는 해당 페이지의 미저장 입력도 잃을 수 있으므로 작업 모드 사용 시 주의.
