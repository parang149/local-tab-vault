# 예정 작업: 작업 모드에서 중복 탭 함께 닫기

상태: 1.7.0 구현 완료. 최종 동작과 검증 결과는 UPDATE-1.7.0.md 참조.

## 요구사항

- 작업 시작 ON 상태에서 보관함에 연결된 탭 하나를 사용자가 닫으면, URL 전체가 정확히 같은 나머지 일반 창 탭도 함께 닫음.
- 같은 URL 탭들이 모두 닫힌 것을 확인한 후 해당 URL의 미완료 보관 항목을 완료 처리하고 완료 시각을 기록.
- 완료 처리 후 다음 미완료 항목 하나만 열기.
- 다음 항목은 기존 규칙대로 아래쪽 우선, 아래쪽이 없으면 위쪽. 남은 항목이 없으면 열지 않음.
- 작업 OFF 상태에는 중복 탭 자동 닫기·자동 완료·다음 항목 열기를 실행하지 않음.
- 비공개 창, 확장 관리 화면, 제한 URL 등 기존 안전 제외 대상은 유지.

## 구현 시 안전 조건

- 자동으로 닫는 중복 탭들의 닫힘 이벤트가 다시 작업을 시작하지 않도록 작업 단위 잠금/식별자를 둠.
- 완료 처리와 다음 항목 열기는 중복 이벤트와 관계없이 한 번만 실행.
- 닫기 직전에 탭 ID와 URL을 재확인하고 다른 주소로 바뀐 탭은 닫지 않음.
- 일부 닫기 실패 또는 동일 URL 탭이 남아 있는 경우 완료 처리 및 다음 항목 열기를 중단하고 안내.
- 창 전체 닫기와 브라우저 종료를 일반적인 작업 완료 신호로 처리하지 않음.
- 작업 모드 안내에 중복 탭도 자동으로 함께 닫힌다는 동작을 명시.
- 현재 열린 탭만 ‘확인 중’으로 표시하는 예정 작업과 함께 상태 전이를 점검.

## 검증 및 배포

- 가상 데이터로 동일 URL 여러 탭, 여러 창, 중복 닫힘 이벤트, URL 변경, 일부 실패, 작업 OFF, 마지막 항목을 테스트.
- 실제 사용자 탭은 개발·테스트에서 조작하지 않음.
- 배포는 ZIP 없이 버전별 폴더로 제공.
