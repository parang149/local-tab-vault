# 1.5.0 변경 및 검증

- 전체 화면: 작업 토글을 헤더로 이동하고 ON/OFF 스위치로 표시.
- 전체 화면/사이드패널: ‘열린 탭 보관’ 한 번으로 수집·중복 확인·저장·읽기 검증.
- 사이드패널: 현재 창/모든 일반 창 선택, 중복 합치기, 저장 후 백업 및 별도 닫기 영역 표시.
- 저장 실패 시 이전 닫기 권한도 무효화. 저장 버튼 자체는 탭을 닫지 않음.
- 기존 데이터베이스 스키마와 확장 ID 유지. 새 권한 없음.

## 변경 파일

extension/manager.html, sidebar.html, manager.js, controls.css, service.js,
background.js, manifest.json, package.json, package-lock.json,
tests/controls.test.js, tests/vault.test.js, tests/browser.mjs, README.md.

## 검증

- npm test: 28개 통과. 가상 탭 2,000개 저장·검증·백업·닫기·단일 열기·휴지통 복원 포함.
- 두 화면의 실제 HTML/JS를 jsdom으로 실행: 상단 스위치, 페이지 선택, 한 번 클릭 저장,
  연속 클릭 방지, 현재 창 인수 전달, 사이드패널 백업 영역 노출, 작업 상태 갱신 확인.
- 2,000개 목록: 페이지당 DOM 50개, 느린 페이지 약 48ms (jsdom; 실제 화면 성능 측정 아님).
- 격리된 Headless Edge 시각 검증은 브라우저 시작 오류로 실행하지 못함.
- 실제 Floorp 및 사용자의 탭은 조작하지 않음. 최종 배치와 동작은 5~10개 시험 탭으로 확인 필요.
