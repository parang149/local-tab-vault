# 1.6.0

- 전체 화면의 선택 작업에 ‘선택 미확인’ 추가. 완료/확인 중 항목을 미확인으로 변경하며 완료 시각은 해제하고 메모·태그·URL은 보존합니다.
- 전체 화면에서 ‘휴지통 보기’를 켜면 ‘휴지통 비우기’ 표시. 선택/검색/페이지와 무관한 휴지통 전체 영구 삭제입니다.
- ‘영구 삭제 N’ 문구를 직접 입력해야 실행합니다. 확인 중 휴지통 내용이 바뀌면 중단합니다.
- 항목 및 연결된 저장 작업·체크포인트·작업 기록을 단일 트랜잭션으로 삭제하고 이전 탭 닫기 권한을 무효화합니다. 실제 열린 탭은 건드리지 않습니다.
- JSON 백업 파일은 삭제하거나 수정하지 않습니다. 영구 삭제 전 필요하면 백업하세요.
- 사이드패널의 간결한 목록 구성은 유지합니다. 일괄 작업 및 휴지통 관리는 ‘전체 화면’에서 사용하세요.

변경 파일: extension/{manager.html,sidebar.html,manager.js,background.js,service.js,db.js,manifest.json}, package.json, package-lock.json, tests/{vault.test.js,controls.test.js}.

검증: 가상 탭 2,000개 흐름 포함 자동 테스트 31개. 미확인 복귀, 영구 삭제 확인·대상 변경 차단, 연결 기록 정리, 트랜잭션 실패 복구, 버튼 연결 점검. 실제 Floorp 화면은 미검증이며 실제 사용자 데이터 및 탭은 조작하지 않았습니다.

배포: dist/local-tab-vault-1.6.0 폴더만 제공. 업데이트 전 JSON 백업 권장.
