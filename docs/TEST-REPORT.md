# 1.4.0 테스트 보고서

- 자동 테스트: **24/24 통과**. 시스템 테마 설정, 완료 항목 별도 필터, 작업 모드 중복 URL 종료/다음 항목 순서를 포함합니다.
- 가상 2,000탭 저장→백업 검증→명시적 닫기 승인→하나 열기→완료 시각→휴지통/복원/가져오기 흐름 테스트.
- 2,000 항목 검색·정렬·페이지네이션은 50개씩만 DOM 렌더링.
- Floorp 실제 탭은 조작하지 않았습니다. 브라우저 통합 테스트는 이 환경에서 격리 Edge가 즉시 종료되어 실제 브라우저 렌더링 검증이 제한됩니다.
- `npm run build`는 ZIP을 만들지 않고 `dist/local-tab-vault-1.4.0` 설치 폴더만 생성합니다.

사이드패널 테마 자동 변경, 하단 페이지 드롭다운, 완료 보기는 Floorp에서 설치 후 확인이 필요합니다. 먼저 5~10개 테스트 탭에서 작업 토글을 시험하세요.
